# Ascentia – Placement Portal

This project is a web-based Placement Portal developed as part of the MAD2 (Modern Application Development–2) course. The application is designed to simplify and streamline the campus recruitment process by providing a centralized platform for three primary stakeholders: Admin, Companies, and Students.

The system enables efficient management of placement activities through secure role-based access, allowing companies to post job opportunities, students to explore and apply for positions, and administrators to oversee the complete recruitment workflow. The application emphasizes a responsive user experience, scalable backend architecture, secure authentication, and asynchronous task processing while maintaining a clean and modular design.
